Your_Post 📝
A professional full-stack web application for managing posts. This project features a clean separation between the frontend and backend for better scalability.

🚀 Project Structure
This repository contains:

frontend: React application powered by Vite.

backend: Node.js and Express server.

🛠️ Tech Stack
Frontend: React, Vite, CSS

Backend: Node.js, Express

Database: MongoDB (if applicable)

💻 Getting Started
Follow these steps to run the project on your local machine:

1. Clone the repository
Bash
git clone https://github.com/priyadharshini-15mp/Your_Post.git

2. Run Backend
Bash
cd backend
npm install
npm start

3. Run Frontend
Bash
cd frontend
npm install
npm run dev
